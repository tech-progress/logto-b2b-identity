## Source recipe and default use

A repository containing source recipes and pinned upstream references does not thereby redistribute the assembled images. No missing permission or unresolved original notice was identified for the newly authored source recipe or this exact wrapper production closure. This conclusion is limited to those inputs and this distribution mode; copied notices retain their original grants.

UAParser v2 is a concrete runtime exception. Tagged [audit middleware](https://github.com/logto-io/logto/blob/79e9e3b0d9f505260d09c80d8a015e56fbc0ec01/packages/core/src/middleware/koa-audit-log.ts), [session utilities](https://github.com/logto-io/logto/blob/79e9e3b0d9f505260d09c80d8a015e56fbc0ec01/packages/shared/src/utils/session.ts) and [console MFA display](https://github.com/logto-io/logto/blob/79e9e3b0d9f505260d09c80d8a015e56fbc0ec01/packages/console/src/components/MfaFactorName/index.tsx) use it. It is not an unused connector. AGPL §§4–6 govern conveying covered material; §13 addresses modified versions used over a network. Determine the covered combined-work/source-offer scope if modifying the covered application or distributing binaries. This review does not decide that every separate recipe file inherits AGPL, or that a source link alone fulfills all combined-work obligations.

The retained Cloud package has ELv2 terms even though the Dockerfile removes the top-level Cloud workspace. Imports found in tagged core source are type imports; [Cloud mode](https://github.com/logto-io/logto/blob/79e9e3b0d9f505260d09c80d8a015e56fbc0ec01/packages/shared/src/node/env/GlobalValues.ts) requires `IS_CLOUD`, which the original recipe does not set. Package presence does not demonstrate that default requests expose substantial Cloud functionality. The public tag is not asserted to contain this package's complete preferred source; ELv2 itself does not impose a corresponding-source duty. Enabling its functionality requires a fresh assessment of the actual service use and grant.

## Finite unresolved boundaries

No external SAML provider is installed by this recipe. Embedded XML/native grant and source correspondence was not established. This is a disclosed limit for SAML or binary-distribution expansion, not an identified missing permission for publishing a Dockerfile pin.

Cached Alpine filesystems include GPL/LGPL programs and runtime libraries; the Node grant also preserves native/embedded notices. Any assembled-image redistribution requires the applicable grants, exact source packages and exceptions, and any required source/offers for that artifact. The PostgreSQL Debian copyright likewise preserves multiple component grants. This finite source-recipe review does not certify a redistributable image or pursue every installed package as a universal clearance exercise. Preserve product branding and upstream artwork notices; no trademark endorsement is inferred.

Retain these AGPL/ELv2/Artistic/native exceptions in public documentation. No image or pin change is recommended by this review.
